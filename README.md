# 🍑 덕분에 농원 · 복숭아 판매 사이트

햇사레 감곡 복숭아를 소개하고 주문받기 위한 **한 장짜리 정적 웹사이트**입니다.
데이터베이스도, 서버도 필요 없습니다. `index.html` 파일만 열면 바로 동작합니다.

## 화면 구성

| 구역 | 내용 |
|---|---|
| 히어로 | "부모님이 좋아하시는 맛있는 복숭아 · 싱그러운 여름의 선물" |
| 농원 자랑 | 신선한 복숭아 / 정성 가득 포장 / 수확 당일 발송 |
| 사진 갤러리 | 사진 클릭 시 크게 보기(좌우 이동, ESC 닫기) |
| 상자 안내 | 실중량 4kg, 박스작업 4.7~4.9kg, 개수별 크기 비교 |
| 가격안내 | 10·11개 35,000원 / 12·13개 30,000원 / 14·15개 25,000원 / 17개·못난이 20,000원 |
| 주문하기 | 수량 선택 → 택배비 포함 합계 자동 계산 → 주문 문자 자동 작성 |
| 자주 묻는 질문 | 무게, 가격 차이, 못난이, 배송, 보관법 |

주문은 **문자·전화**로 받습니다. 손님이 수량과 주소를 입력하면 보낼 문자 내용이 자동으로 만들어지고,
`주문서 복사하기` / `문자로 보내기` / `전화 걸기` 버튼으로 바로 연락할 수 있습니다.
입력한 개인정보는 **어디에도 전송되지 않고** 그 사람의 브라우저 안에서만 사용됩니다.

## 보는 방법

`index.html` 을 더블클릭하면 끝입니다. 개발 중이라면 간단한 서버를 띄워도 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 내용 수정하기 (여기만 고치면 됩니다)

가격·연락처·사진 목록은 모두 **`assets/js/site-data.js`** 한 파일에 모여 있습니다.
HTML 은 건드릴 필요가 없습니다.

### 1. 전화번호 넣기 — 가장 먼저 해주세요

```js
const SITE = {
  phone: '010-0000-0000',   // ← 실제 번호로 바꿔주세요
};
```

> **계좌번호는 사이트에 넣지 않습니다.**
> 인터넷에 상시 공개된 계좌번호는 사칭·도용에 쓰이기 쉽고 예금주 실명까지 노출됩니다.
> 주문 문자를 받으신 뒤 답장으로 개별 안내해주세요.

### 2. 가격 바꾸기

```js
const PRODUCTS = [
  { id: 'gift', count: '10 · 11개', price: 35000, badge: '선물용', desc: '...' },
  // ...
];
```

`price` 숫자만 고치면 가격표와 주문 계산기에 함께 반영됩니다.

### 3. 택배비 바꾸기

```js
const SHIPPING = { one: 4000, two: 5000, note: '...' };
```

세 상자 이상은 두 상자씩 묶어서 계산합니다. (예: 3상자 = 5,000 + 4,000 = 9,000원)

## 사진

메인 사진 한 장과 갤러리 사진 여섯 장이 이미 들어가 있습니다.

휴대폰으로 찍은 원본은 한 장에 3MB 가 넘는 것도 있어 그대로 쓰면 화면이 느리게 뜹니다.
그래서 **긴 쪽 1400px 로 줄인 사본**(`peach-hero.*`, `gallery-1` ~ `gallery-6`)을 만들어 쓰고,
원본(`peach.png`, `1.jpg` ~ `6.jpg`)은 폴더에 그대로 보관하고 있습니다.

사진을 바꾸거나 더 넣는 방법은 `assets/images/README.md` 를 봐주세요.

## 인터넷에 올리기

정적 파일뿐이라 어디에 올려도 됩니다. 가장 간단한 방법은 GitHub Pages 입니다.

1. GitHub 저장소 → **Settings → Pages**
2. Source 를 `Deploy from a branch` 로 두고, 브랜치를 고른 뒤 폴더는 `/ (root)`
3. 저장하면 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 만들어집니다

Netlify · Vercel 도 폴더를 그대로 끌어다 놓으면 배포됩니다.

## 폴더 구조

```
.
├── index.html                # 사이트 본문
├── assets/
│   ├── css/style.css         # 디자인
│   ├── js/site-data.js       # ★ 가격·연락처·사진 목록 (여기만 수정)
│   ├── js/main.js            # 갤러리·계산기 동작
│   └── images/               # 복숭아 사진을 넣는 곳
└── README.md
```
