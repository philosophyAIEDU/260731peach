# 사진 폴더

| 파일 | 쓰이는 곳 |
|---|---|
| `peach-hero.webp` · `peach-hero.jpg` | **메인 화면 큰 사진** |
| `peach-og.jpg` | 카카오톡·문자로 링크 공유할 때 뜨는 미리보기 |
| `gallery-1` ~ `gallery-6` (webp · jpg) | **복숭아 사진 갤러리** 6장 |

## 원본은 그대로 보관돼 있습니다

| 원본 | 만들어진 사본 |
|---|---|
| `peach.png` (2.6MB) | `peach-hero.*` |
| `1.jpg` ~ `6.jpg` | `gallery-1` ~ `gallery-6` |

원본을 그대로 쓰면 휴대폰에서 사진이 뜨는 데 오래 걸립니다.
특히 `5.jpg` · `6.jpg` 는 한 장에 3MB 가 넘어서, 여섯 장만 열어도 데이터가 10MB 가까이 나갑니다.
그래서 긴 쪽 1400px 로 줄이고 용량을 확 낮춘 사본을 만들어 쓰고 있습니다.
(예: `5.jpg` 3.2MB → `gallery-5.webp` 172KB)

`5.jpg` · `6.jpg` 는 사진에 "옆으로 눕혀서 보라"는 회전 정보가 들어 있었습니다.
사본에는 회전을 실제로 적용해 구워 넣어서, 어느 브라우저에서 열어도 똑바로 보입니다.

## 사진을 바꾸거나 더 넣고 싶으실 때

새 사진을 이 폴더에 올리신 뒤 **저에게 말씀해주세요.** 위와 같은 방식으로
크기를 줄이고 목록에 넣어드리겠습니다.

직접 하고 싶으시면 `assets/js/site-data.js` 의 `GALLERY` 목록에 한 줄 추가하면 됩니다.

```js
const GALLERY = [
  { src: 'assets/images/gallery-1.jpg', webp: 'assets/images/gallery-1.webp', caption: '한 상자에 가지런히 담은 복숭아' },
  // 이런 식으로 한 줄 추가 (webp 사본이 없으면 webp 줄은 빼도 됩니다)
  { src: 'assets/images/새사진.jpg', caption: '설명을 적어주세요' },
];
```

목록에 적은 사진 파일이 없으면 그 칸은 파일 이름이 적힌 안내 카드로 바뀌므로,
사이트가 깨지지는 않습니다.

## 사진 촬영 팁

- **가로로** 찍은 사진이 가장 예쁘게 들어갑니다 (갤러리는 4:3 으로 잘립니다).
- 밝은 낮에 자연광으로 찍으면 복숭아 색이 가장 잘 살아납니다.
- 상자에 담긴 모습, 저울에 올린 모습, 밭 풍경이 손님들이 가장 궁금해하는 사진입니다.
