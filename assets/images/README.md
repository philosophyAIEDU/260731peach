# 사진 넣는 곳

## 메인 사진 (이미 들어가 있습니다)

| 파일 | 쓰이는 곳 |
|---|---|
| `peach.png` | 사장님이 올려주신 원본 (2.6MB) — 보관용 |
| `peach-hero.webp` · `peach-hero.jpg` | **메인 화면 사진** (164KB / 231KB) |
| `peach-og.jpg` | 카카오톡·문자로 링크 공유할 때 뜨는 미리보기 |

원본 2.6MB 를 그대로 쓰면 휴대폰에서 첫 화면이 느리게 떠서, 가로 1400px 로 줄이고
용량을 94% 줄인 사본을 만들어 쓰고 있습니다. 최신 브라우저는 `webp`, 옛날 브라우저는
`jpg` 를 자동으로 골라 받습니다.

**메인 사진을 다른 사진으로 바꾸시려면** 새 사진을 올리신 뒤 저에게 말씀해주세요.
같은 방식으로 줄여서 갈아 끼워드리겠습니다.

이 폴더에 복숭아 사진을 넣고, `assets/js/site-data.js` 의 `GALLERY` 목록에
파일 이름을 적어주시면 갤러리에 나타납니다.

이 이름 그대로 넣으면 아무것도 수정할 필요가 없습니다.
다른 이름을 쓰고 싶으면 `site-data.js` 의 `GALLERY` 목록만 고쳐주세요.

## 사진 팁

- **가로로** 찍은 사진이 가장 예쁘게 들어갑니다 (4:3 비율로 잘립니다).
- 휴대폰 원본 사진은 용량이 커서 화면이 느리게 뜹니다. **긴 쪽 1600px 정도**로 줄여주세요.
- 파일 하나에 **500KB 이하**를 권합니다.
- 밝은 낮에 자연광으로 찍으면 복숭아 색이 가장 잘 살아납니다.

## 사진이 아직 없어도 괜찮아요

파일이 없으면 그 칸은 파일 이름이 적힌 안내 카드로 표시됩니다.
사이트가 깨지지 않으니 사진은 준비되는 대로 하나씩 채워 넣으시면 됩니다.
